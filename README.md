## 🚀 Getting Started

To get this website running locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/shibusharma1/kantipur-vet-distributors-design-php.git
````

2. **Set up a local PHP server**

   You can use built-in PHP server:

   ```bash
   cd kantipur-vet-distributors-design-php
   php -S localhost:8000
   ```

3. **Open in Browser**

   Visit: `http://localhost:8000/index.php`

⚠️ Make sure your PHP environment supports minimum PHP 7.x or above.
